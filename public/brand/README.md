# Clubhouse 9 Brand Assets

Product-level Clubhouse 9 artwork lives here.

- `clubhouse9-wordmark.png` - full horizontal wordmark for auth/onboarding/email.
- `clubhouse9-mark.png` - compact C9 shield/mark for the app shell.
- `clubhouse9-icon-*.png` - favicon, PWA, and mobile app icon variants.

Organization/team logos, such as Metrolina assets, should remain separate product data and should not replace these product-brand files.
